# TsiYuki Core

Shared editor utilities (localization, UI styles, NDMF error reporting, undo-safe edits, generated animator pieces) used by TsiYuki's VRChat tools.

> Work in progress. Not released yet.

## Install

Add the TsiYuki VPM listing to VCC / ALCOM: <https://tsiyukino.github.io/vpm-repos/>, then add **TsiYuki Core** to your project.
